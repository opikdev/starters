# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and welcoming, and don't harass anyone. Maintainers may remove comments or contributors that break these rules.

To report a problem privately, use **Report a vulnerability** on this repo's **Security** tab and say it's a conduct report. Maintainers will keep your report confidential.
